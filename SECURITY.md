# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.8.x   | :white_check_mark: |
| < 0.8.0 | :x:                |

## Reporting a Vulnerability

The Harnemon team takes security issues seriously.

If you discover a security vulnerability:
1. **Do not create a public GitHub issue.**
2. Please report security issues privately via GitHub Private Vulnerability Reporting or email.
3. Include clear reproduction steps.

We will acknowledge receipt within 48 hours and coordinate a patch release.
